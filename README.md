# Rural Credit Analysis Using Python

## Overview
This project analyzes state-wise agricultural credit sanctions and utilization using NABARD rural finance data.

The project focuses on:
- agricultural credit distribution
- utilization efficiency
- state-wise comparisons
- exploratory data analysis
- financial visualization

---

## Objectives
- Analyze agricultural credit trends
- Compare sanctioned vs utilized credit
- Identify underutilized agricultural credit
- Generate state-wise insights
- Visualize rural finance patterns

---
